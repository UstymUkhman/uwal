Device ​

Defined in: Device.js:19

Classdesc ​

Middleware for WebGPU APIs. Used to create Renderer and Computation stages, Texture helpers and GPUQuerySets. It can require a GPUAdapter and a GPUDevice with specified features and limits and destroy resources like GPUBuffers, GPUTextures GPUQuerySets and the current GPUDevice.
